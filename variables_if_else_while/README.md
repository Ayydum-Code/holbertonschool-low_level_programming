# C - Variables, if, else, while

This project covers the basics of C programming: declaring and using variables, making decisions with if/else statements, and repeating code with while loops.

## Learning objectives

- Declare variables of different types (int, char, float) and use arithmetic, relational and logical operators
- Control program flow with if, else if and else
- Repeat code with while and for loops
- Print output with putchar
- Write code that passes Betty style and compiles with gcc -Wall -Werror -Wextra -pedantic -std=gnu89

## Requirements

- Ubuntu 20.04 LTS, gcc
- All files end with a new line
- Code follows the Betty style
